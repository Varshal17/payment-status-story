# Where's my money?

A scroll-driven story that makes the case for one payment status system across every product, rail and screen, with the strategy and action plan for leadership.

Open `index.html` in a browser, or view the GitHub Pages site for this repository.

Scroll mechanics are adapted from The Pudding's open-source [svelte-starter](https://github.com/the-pudding/svelte-starter) `Scrolly` helper (MIT), rewritten in plain JavaScript.

Customer names, merchants and amounts are illustrative. Market labels and timings come from public sources checked on 18 Nov 2026.
